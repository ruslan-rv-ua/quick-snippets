## Що таке QuickSnippets?

QuickSnippets — невеликий портативний десктопний застосунок, що дозволяє зберігати особисту бібліотеку текстових сніпетів і вставляти будь-який з них у будь-який застосунок за лічені секунди.

Натисніть **Ctrl+Alt+Space** з будь-якого місця на робочому столі. Вікно з'являється, ви вводите кілька літер, щоб знайти потрібний сніпет, натискаєте **Enter** — і він у буфері обміну. Без хмари, без телеметрії, без встановлення.

Чутливі сніпети можна зашифрувати локально за допомогою AES-256-GCM, щоб лише ви — з правильним паролем — могли до них отримати доступ.

## Можливості

- **Миттєвий доступ** — глобальна гаряча клавіша показує вікно з будь-якого застосунку
- **Швидкий пошук** — нечіткий пошук фільтрує сніпети під час введення
- **Зашифровані сніпети** — захистіть конфіденційний вміст паролем (шифрування AES-256-GCM, ключі ніколи не покидають пристрій)
- **Повне управління з клавіатури** — кожна дія має комбінацію клавіш; миша необов'язкова
- **Підтримка скринрідерів** — розроблено для NVDA, JAWS та Windows Narrator з першого дня
- **Портативність** — без інсталятора, без реєстру, без `AppData`; весь застосунок знаходиться в одній папці
- **Системний трей** — не заважає, коли не використовується; клацніть правою кнопкою на іконці трею для швидких дій
- **Світла та темна теми** — перемикайте однією комбінацією або через Налаштування
- **Три мови** — англійська, українська та німецька; мова визначається автоматично із системи
- **Один екземпляр** — повторний запуск застосунку просто переводить фокус на існуюче вікно
- **Автоприховування при втраті фокусу** — вікно зникає при переключенні, як лаунчер

## Доступність

QuickSnippets розроблено з пріоритетом доступності. Кожна функція запроєктована для роботи без миші та правильного оголошення допоміжними технологіями.

- Усі інтерактивні елементи мають описові ARIA-мітки та ролі
- Список сніпетів є правильним `listbox` з `aria-activedescendant`; скринрідери оголошують вибраний сніпет та його позицію (наприклад, «Привітання, 1 з 12»)
- Фокус утримується всередині модальних діалогів і повертається до елементу, що їх відкрив
- Live region оголошують підтвердження копіювання та повідомлення про помилки без переміщення фокусу
- Дерево доступності WebView2 примусово ініціалізується при запуску, тому скринрідери працюють коректно навіть при запуску в мінімізованому вигляді в треї
- `Ctrl+Shift+Space` озвучує поточний вибраний сніпет через polite live region
- Підтримуються великий контраст і зміни системної теми
- Поля форм вимикають автодоповнення браузера, щоб уникнути плутанини допоміжних технологій

## Безпека

- **Лише локальне шифрування.** Зашифровані сніпети зберігаються як шифртекст AES-256-GCM у локальній базі даних SQLite. Розшифрований вміст ніколи не надсилається у процес фронтенду.
- **Надійне виведення ключів.** Ключі шифрування виводяться з вашого пароля за допомогою PBKDF2-HMAC-SHA256 з 100 000 ітерацій, унікальною випадковою сіллю та унікальним випадковим nonce при кожному шифруванні.
- **Операції з буфером обміну в Rust.** Коли ви активуєте зашифрований сніпет, бекенд Rust розшифровує його і записує безпосередньо в буфер обміну. Відкритий текст ніколи не перетинає кордон IPC.
- **Без мережевого доступу.** Застосунок не встановлює вихідних з'єднань.

## Встановлення

QuickSnippets — портативний застосунок, інсталятор не потрібен.

1. Перейдіть на [сторінку Releases](https://github.com/ruslan-rv-ua/quick-snippets/releases).
2. Завантажте останній `quick-snippets-windows-x64-vX.Y.Z.zip`.
3. Розпакуйте ZIP у будь-яку папку (наприклад, `C:\Tools\QuickSnippets\`).
4. Запустіть `quick-snippets.exe`.

### Встановлення через Scoop

Якщо ви використовуєте [Scoop](https://scoop.sh/), можна встановити QuickSnippets з офіційного бакета:

```powershell
scoop bucket add ruslan-rv-ua https://github.com/ruslan-rv-ua/scoop-bucket
scoop install quick-snippets
```

База даних сніпетів (`snippets.db`) та налаштування (`settings.json`) зберігаються в тій самій папці, що й виконуваний файл. Щоб перемістити або створити резервну копію застосунку, скопіюйте всю папку.

> **Контрольна сума SHA-256** — файл `.sha256` додається до кожного релізу для перевірки.

## Початок роботи

### Перший запуск

При першому запуску список сніпетів порожній. Натисніть **Ctrl+N** (або **Insert**), щоб створити перший сніпет.

Дайте йому коротку, легку для запам'ятовування назву — саме за нею виконується пошук. Вставте або введіть вміст. Опційно встановіть прапорець **Зашифровано**, щоб захистити його паролем. Натисніть **Ctrl+Enter** або натисніть **Зберегти**.

### Пошук та копіювання сніпету

1. Натисніть **Ctrl+Alt+Space** з будь-якого застосунку.
2. Почніть вводити назву сніпету. Список фільтрується в реальному часі.
3. Використовуйте **Стрілки вгору / вниз** для переміщення по результатах.
4. Натисніть **Enter**, щоб скопіювати вибраний сніпет у буфер обміну.
5. Перейдіть до цільового застосунку та вставте (**Ctrl+V**).

Вікно QuickSnippets автоматично приховується при переключенні.

### Системний трей

Іконка застосунку знаходиться в системному треї. Клацніть правою кнопкою для швидкого доступу до **Показати**, **Новий сніпет**, **Налаштування** та **Вийти**.

## Комбінації клавіш

### Глобальні (працюють з будь-якого застосунку)

| Комбінація | Дія |
|---|---|
| Ctrl+Alt+Space | Показати / сховати вікно QuickSnippets |

### У головному вікні

> Усі літерні комбінації (Ctrl+N, Ctrl+E, Ctrl+D, Ctrl+F тощо) використовують фізичне
> положення клавіші, тому вони працюють незалежно від активного розкладання ОС (наприклад, українського).

| Комбінація | Дія |
|---|---|
| Стрілка вгору / вниз | Переміщення виділення у списку сніпетів |
| Home / End | Перехід до першого / останнього сніпету |
| Enter | Копіювати вибраний сніпет у буфер обміну |
| Ctrl+N або Insert | Створити новий сніпет |
| Ctrl+E | Редагувати вибраний сніпет |
| Delete або Ctrl+D | Видалити вибраний сніпет |
| Ctrl+F або / | Сфокусуватися на полі пошуку |
| Ctrl+, | Відкрити Налаштування |
| Ctrl+Shift+T | Перемикати світлу / темну тему |
| Ctrl+Shift+Space | Оголосити вибраний сніпет (скринрідер) |
| Escape | Закрити модальне вікно / очистити пошук |
| Alt+F4 | Вийти з застосунку |

### У формах та діалогах

| Комбінація | Дія |
|---|---|
| Ctrl+Enter | Підтвердити / зберегти (працює в усіх діалогах, включно з підтвердженням виходу та видалення) |
| Escape | Скасувати та закрити модальне вікно |

## Налаштування

Відкрийте Налаштування через **Ctrl+,** або меню трею.

| Налаштування | Опис |
|---|---|
| Тема | Світлий або темний інтерфейс |
| Мова | Англійська, українська, німецька або автовизначення з системи |
| Запускати у треї | Приховати вікно при запуску; видима лише іконка трею |
| Запускати з Windows | Запускати QuickSnippets автоматично при старті Windows |
| Підтверджувати закриття | Показувати діалог підтвердження перед виходом |
